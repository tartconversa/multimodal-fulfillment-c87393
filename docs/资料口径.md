# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

cargo_id为可拆分实物支流，parent分拆后不与子流同时计存量。actual_loads每行是该段实际装载kg和m3，orders_bridge是明确归属，不按主单分单编号猜。装载同货同段不得超过该流重量，预订单不证明实运。计费重为合同max(actual_kg,volume_m3×volumetric_kg_m3)。账单scope_id决定一次最低收费作用范围，先对范围算总价再按basis分配，取消费按caused_order直接归因，不按当前实载洗掉。invoice是正式实际发生费用，payment只表示支付而非新增费用；无invoice时按quote给预估成本并注明。货运收入按已交付重量占该订单总重量乘约定总价确认；未交份额仍保留对应在途成本。实际币种金额与人民币金额并存，quote、invoice、payment按各自日期汇率，汇兑差单列。吨公里用实际kg/1000乘真实段km，只计有货区段。

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

fixed且caused_order非空的取消费全部归该订单，其余fixed共享费按范围内实际订单数均分。父流订单归属传给子流，不同时连接父子重复费用。正式账单为实际发生额，与理论合同费用不同则保留价差待核，不覆盖原始数量。

quotes在cost_documents中表示该scope的原始暂估总额，invoice为正式总额，二者均不再次套最低收费；合同rate/minimum用于核查理论总额及解释价差。共享分配仍用scope约定的basis与实际装载关系，未履约订单的成本保留不随收入确认全部释放。
